# Keyboard shortcuts

**Help → Keyboard Shortcuts** (Ctrl+/, ⌘/ on macOS) lists them in the app too, always up to date.

On macOS, use ⌘ where this page says Ctrl, unless it says otherwise.

## Files

| Action | Keys |
|---|---|
| Open files | Ctrl+O |
| Open a remote log (SFTP) | Ctrl+Shift+O |
| Open a web address | Ctrl+Shift+U |
| Open a folder's files | File → Open Folder… (no shortcut) |
| Search in a folder | Ctrl+Shift+F |
| Merge files by time | Ctrl+Shift+M |
| Compare files (CSV and TSV as tables) | File → Compare Files…, or Compare Files… on the start page (no shortcut) |
| Compare logs by message | Ctrl+Shift+D |
| Export lines shown by filters | Ctrl+Shift+E |
| Close the tab | Ctrl+W, or a middle click on the tab |
| Quit | Ctrl+Q (⌘Q on macOS) |
| Settings | Ctrl+, |

## Find and filters

| Action | Keys |
|---|---|
| Find in this log (the selected text becomes the search) | Ctrl+F |
| Next / previous match in the find bar | Enter / Shift+Enter |
| Next / previous match anywhere | F3 / Shift+F3 (also ⌘G / ⇧⌘G on macOS) |
| Find All | Ctrl+Enter in the find bar |
| Close the find bar | Esc |
| Close the selected Find results search | Shift+Esc |
| Matching lines only / all lines | Ctrl+Shift+H |
| In Find results: fold or open a search | Click its header, or Enter / ← / → |
| In Find results: go to the line | Click, double-click, or Enter |
| In Folder search: search / stop | Enter / Esc |

## Moving around

| Action | Keys |
|---|---|
| Go to line | Ctrl+L |
| Go to time | Ctrl+Shift+L |
| Next / previous error | F8 / Shift+F8 |
| In a comparison: next / previous difference | F7 / Shift+F7 |
| Follow the current line's request (or the selected text) | Ctrl+Shift+R |
| Bookmark the current line | Ctrl+F2 |
| Next / previous bookmark | F2 / Shift+F2 |
| Top / bottom of the file | Ctrl+Home / Ctrl+End |
| Scroll sideways | ← → |

## The view

| Action | Keys |
|---|---|
| Follow the end of the file (tail -f) | Ctrl+T, or End |
| Load changes to the file | F5 |
| Columns | Ctrl+Shift+K |
| Wrap long lines | Alt+Z (⌥Z on macOS) |
| Tree of loggers | Ctrl+Shift+B |
| Fold or open the bottom panel | Ctrl+J |
| Bigger / smaller font | Ctrl+= / Ctrl+- |

## Selecting and copying

| Action | Keys |
|---|---|
| Copy (with nothing selected, the current line) | Ctrl+C |
| Select all | Ctrl+A |
| Select a word / a line | Double-click / triple-click, or click the line number |
| Extend the selection | Shift+click, Shift+arrows, or drag in the line numbers |

## JVMs

| Action | Keys |
|---|---|
| Attach to a running JVM | Ctrl+Shift+J |
| Heap map: go back out | Backspace |
| Remote file browser: up one folder | Backspace |
