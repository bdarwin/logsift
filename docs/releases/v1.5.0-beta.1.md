A pre-release of Logsift 1.5. Everything Logsift does is now available to AI agents, and to your own programs, by tool calls. The assistant brings its own Copilot.

## What's new

- **Every feature for agents:** 21 new tools: filter (the Filters panel's own engine), timeline, follow a growing log, whole entries, folder and zip listings, column profiles, merged tables, three-way merges, heap dump, histogram, profile and thread dump comparisons, short Flight Recorder recordings (asked every time), bookmarks and log formats.
- **A guide for any model:** the `guide` tool (first in the list), `logsift-mcp skill` and `LogsiftTools.guide()` give the same instructions: which tool for which question, the order to call them in, an example call for every tool, and the mistakes to avoid.
- **Agents may change things, if you let them:** **Settings → Agents → Let agents change things**, or `logsift-mcp --allow-changes`. Agents can then save new files (lines, a comparison, a merge result), set bookmarks, add log formats and describe log locations. They never replace or delete a file. Off by default.
- **Embed Logsift:** MCP over standard input and output from any language, or `logsift.embed.LogsiftTools` in Java (the jars in the `any-java21` zip).
- **`npx -y logsift-mcp`:** the MCP server from npm, listed in the MCP Registry as `io.github.bdarwin/logsift`.
- **The assistant brings its own Copilot**, so a Copilot update can't break it. Sign in as you already are (Copilot's `/login`, or the GitHub CLI).
- Everything listed as unreleased in the [changelog](https://github.com/bdarwin/logsift/blob/main/CHANGELOG.md).

This is a pre-release: Logsift doesn't offer it as an update, and installers show it as 1.5.0.

The native downloads include their own Java runtime. They are not code-signed yet:
- **macOS:** if it says the app is damaged or can't be opened, run `xattr -dr com.apple.quarantine /Applications/Logsift.app`.
- **Windows:** SmartScreen may warn on first launch: click **More info → Run anyway**.
