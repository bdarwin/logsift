Logsift 1.4 brings the assistant (Beta): GitHub Copilot or Claude Code beside your logs, answering with Logsift's own tools on what you have open. Tables become grids, and big tables answer in milliseconds.

## What's new

- **The assistant (Beta):** **View → Assistant** (⌘I, Ctrl+I) opens a chat in a tab, at the side of the window, or in a window of its own. It reads the logs you have open with Logsift's tools, knows which log is shown and which lines you selected, and cites lines as links that take you there. It uses your own GitHub Copilot or Claude Code (**Settings → Assistant → Who answers**), and you can sign in to Copilot from Logsift. It can only read, and asks before it opens a file you didn't open, takes a thread dump or a histogram. Each answer shows its model, cost and time; every chat is kept and searchable.
- **GC charts in the chat:** asked about a GC log, the assistant shows the heap chart above its answer, drawn by Logsift (no tokens spent on it), with **Show GC Charts** for the rest.
- **Running JVMs:** the assistant and coding agents can list a service's JVMs and take a thread dump or a heap histogram (asked first, never a heap dump). **JVM → JVM Connections (SSH, JMX)…** keeps where each one runs.
- **Tables are grids of cells:** click a cell, Shift+click or drag a block, **Ctrl+C** pastes into a spreadsheet as cells. Wide tables open about twice as fast and scroll smoothly.
- **Big tables in milliseconds:** filters, value counts and queries on a CSV of 200 MB or more keep the columns they read, so the next ones take milliseconds. A grown file reads only its new rows. The Query tab joins the other open tables by name, and **Examples** offers queries picked by what each column holds.
- **For coding agents:** `query_examples`, web addresses in `open_log` and `compare_files`, and a skill that knows where your logs are.
- **Fixed:** Query reading files on Windows, Windows showing the name Logsift, and following a request through a log still being read.

## Download

| File | For |
|---|---|
| `Logsift-1.4.0-windows-x64.msi` / `-windows-arm64.msi` | Windows installer (no admin rights needed) |
| `Logsift-1.4.0-windows-x64.zip` / `-windows-arm64.zip` | Windows without installing: unzip, run `Logsift\Logsift.exe` |
| `Logsift-1.4.0-macos-arm64.dmg` / `-macos-x64.dmg` | macOS: Apple Silicon / Intel |
| `Logsift-1.4.0-linux-x64.deb` | Debian / Ubuntu |
| `Logsift-1.4.0-linux-x64.tar.gz` / `-linux-arm64.tar.gz` | Other Linux: unpack, run `Logsift/bin/Logsift` |
| `Logsift-1.4.0-any-java21.zip` | Any OS with Java 21+ installed: run `bin/logsift` |

The native downloads include their own Java runtime. They are not code-signed yet:
- **macOS:** if it says the app is damaged or can't be opened, run `xattr -dr com.apple.quarantine /Applications/Logsift.app`.
- **Windows:** if SmartScreen warns, choose **More info → Run anyway**.
