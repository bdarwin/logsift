Logsift 1.1 makes Logsift easier to install, open files with, and get help in.

## What's new

- **Windows installer** (`.msi`): installs for your user only (no admin rights needed), adds a Start menu entry, and opens `.log` files.
- **Open .log files from your file manager:** double-click, Open With, or drop them on the Dock icon on macOS.
- **One window:** opening another file while Logsift is running opens it in the window that's already open.
- **View another program's output live:** `kubectl logs -f my-pod | logsift -`, `docker logs -f app | logsift -`, `journalctl -f | logsift -`.
- **Help menu:** keyboard shortcuts, documentation, report a bug (with your version and system filled in), and About.
- **Update check:** a button in the toolbar when a new version is out. It is one anonymous request to GitHub at most once a day, and can be turned off in the Help menu.
- **Error window:** if something unexpected happens, you see the details with Copy and Report buttons. Logsift keeps running.

## Download

| File | For |
|---|---|
| `Logsift-1.1.0-windows-x64.msi` / `-windows-arm64.msi` | Windows installer (no admin rights needed) |
| `Logsift-1.1.0-windows-x64.zip` / `-windows-arm64.zip` | Windows without installing: unzip, run `Logsift\Logsift.exe` |
| `Logsift-1.1.0-macos-arm64.dmg` / `-macos-x64.dmg` | macOS: Apple Silicon / Intel |
| `Logsift-1.1.0-linux-x64.deb` | Debian / Ubuntu |
| `Logsift-1.1.0-linux-x64.tar.gz` / `-linux-arm64.tar.gz` | Other Linux: unpack, run `Logsift/bin/Logsift` |
| `Logsift-1.1.0-any-java21.zip` | Any OS with Java 21+ installed: run `bin/logsift` |

The native downloads include their own Java runtime. They are not code-signed yet:
- **macOS:** if it says the app is damaged or can't be opened, run `xattr -dr com.apple.quarantine /Applications/Logsift.app`.
- **Windows:** if SmartScreen warns, choose **More info → Run anyway**.
