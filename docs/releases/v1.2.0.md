Logsift 1.2 reads your own log formats, explains what is going on in a log, and copes much better with big files on network shares.

## What's new

- **Your own log formats:** drop a log file and Logsift works out its layout and timestamps, or paste your logging config (log4j 1.x/2, logback, java.util.logging, Python logging). A config with several layouts makes a format for each, with a live preview of how lines split into columns.
- **Insights:** a new tab showing error bursts, new errors and when they began, silences, restarts and noisy messages, with buttons to jump there, show or hide them.
- **Tree of loggers:** loggers, threads or hosts as a package tree with line counts. Uncheck a branch to hide its lines.
- **Details shows the whole entry**, stack trace included. Select text and Details shows just that, and a **Text | JSON** switch pretty-prints JSON, even JSON inside strings.
- **Columns view:** select text in cells, hide columns you don't need (a chip shows what's hidden; **Show All Columns** brings them back).
- **Network shares:** the window no longer freezes while a big file is read; lines still loading show as gray bars with a *Reading from disk…* badge.
- **Settings** (Ctrl+, / ⌘,): font, tab width, encoding, refresh interval, reopening the last session and more.
- **Format in the status bar:** see how the current log is read, and pick another format if needed.
- **Go menu, menu icons and new toolbar buttons**; a splash screen at startup.
- **Windows:** *Open with Logsift* on the right-click menu of files and folders (it no longer takes over `.log` files), *Open from WSL*, new builds install over the old one, and a running Logsift is closed before install or uninstall.
- Logsift exits fully when its window is closed.

The native downloads include their own Java runtime. They are not code-signed yet:
- **macOS:** if it says the app is damaged or can't be opened, run `xattr -dr com.apple.quarantine /Applications/Logsift.app`.
- **Windows:** if SmartScreen warns, choose **More info → Run anyway**.
